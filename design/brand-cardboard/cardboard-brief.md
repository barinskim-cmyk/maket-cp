# Cardboard — бриф для айдентики

Аналог брифа Rate Setter (design/brand-rate-setter). Третий инструмент линейки Content Pulse.

## Имя

**Cardboard** (полное: Content Pulse Cardboard, bundle id `pulse.content.cardboard`).
Игра слов: card (карточка товара) + board (доска/верстак) + cardboard (картон — материал макета, черновика, коробки с образцами). Инструмент — «картонный верстак»: быстрый честный макет до чистовой вёрстки.

## Одна строка

Вёрстка карточек товара из съёмки — за минуты, локально.

## Что это

Локальное desktop-приложение для фотографа и продакшена. Закидываешь фото со съёмки (или они прилетают сами из Capture One по хоткею) — раскладываешь по карточкам с именованными слотами (Фронт / Спинка / Деталь) — свободные контейнеры для доп. контента — на выходе PDF для клиента и список файлов с путями для ретуши. Фото никуда не копируются и не загружаются: приложение помнит только пути, проект — один файл.

## Кому и когда

Фотограф или контент-менеджер сразу после съёмки: собрать раскладку, показать клиенту, отдать список на ретушь. Ниша Rate Setter — «отобрать», ниша Cardboard — «разложить и отдать».

## Характер

Тот же, что у линейки: рабочий инструмент, а не сервис. Спокойный, честный, без обещаний. Приватность как черта характера: «всё остаётся у тебя на компьютере». Метафора картона: черновик, макет, крафт, ручная работа перед чистовиком.

## Текущий UI (для стыковки айдентики)

- Палитра: чернильный `#1a1a1a`, тёплый бумажный фон `#f2f1ef`, белые карточки, линии `#dcd9d4`, серый текст `#8a8680`. Акцентов-цветов нет, ошибки — приглушённый терракот `#b04a3a`.
- Пунктирные рамки слотов — считываются как «место под фото на макете», можно брать в графику.
- Типографика системная (SF/Segoe), лого в топбаре — CARDBOARD разрядкой 2px, рядом мелкая подпись «вёрстка карточек».
- Никаких иконок и эмодзи в UI (правило всей линейки).

## Что нужно от айдентики

1. **Иконка приложения** — .icns (macOS) и .ico (Windows), мотив на выбор: сетка карточки со слотами / лист картона с раскладкой / CB-монограмма. Желательно родство с Rate Setter (кремовое сердце на тёмном) — общая семья, но свой знак.
2. **Лого/шапка** для топбара и README (текстовое начертание CARDBOARD).
3. Позже: страница-инструкция в стиле лендинга (как rate-setter-standalone/instruction.html).
