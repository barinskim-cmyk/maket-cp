## Воронка (как фотограф приводит бренд)

1. Фотограф бесплатно ведёт съёмку в Maket CP, отправляет бренду share-ссылку на согласование.
2. Бренд-менеджер видит процесс (карточки, версии, комментарии) — первое касание продукта без регистрации.
3. После 2-3 съёмок бренд получает предложение: свой кабинет, вся история съёмок, артикулы сквозь сезоны — 30 000 ₽/мес.
4. Продукт должен показывать бренду ценность в share-виде (метка «работает в Maket CP», аккуратный клиентский UI — см. дизайн-аудит).

## Открытые вопросы (не блокируют, решить по ходу)

1. **Лимиты для бесплатных фотографов** — сейчас без лимитов. Если появится злоупотребление или затраты на storage вырастут — мягкий лимит (например, N активных проектов, старые в архив). Вариант «3 бесплатных проекта» отклонён как барьер канала; вернуться только при реальной проблеме затрат.
2. **Цена brand annual** — после первого платящего бренда.
3. **ФЗ-152 / DPA-срок** для долгосрочного хранения — проработать перед первым брендовым контрактом.

## Следствия для продукта (приоритеты из модели)

- Share-вид — витрина продукта для будущего покупателя (бренда): дизайн-качество клиентского UI = конверсия (см. audits/design-review-2026-07.md, разделы B, G).
- Нужен «брендовый» уровень: кабинет бренда, cross-shoot артикулы — это и есть продаваемая сущность (см. memory project_brand_client_continuity).
- Онбординг фотографа должен быть максимально лёгким (демо-проект, feat0702-demo-project) — канал должен расти без продаж.
- Метрики: считать не только фотографов, но и уникальные бренды, открывавшие share-ссылки — это пайплайн продаж.
