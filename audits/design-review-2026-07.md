# Дизайн-аудит Maket CP — июль 2026

**Что смотрел:** живой веб-клиент (github.io/maket-cp), клиентский share-вид на 380px (проект EKONIKA: 4957 превью, 42 карточки, роль client), лендинг, `css/style.css` (3095 строк, v32), `index.html`, все 16 JS-модулей.

**Недоступно:** `docs/feature-matrix.md` — репозиторий приватный, на Pages файл не выложен (404). Роли восстановлены из кода (`share role: client / viewer / retoucher`, pywebview-десктоп для фотографа).

Формат находки: **[Приоритет] Экран — проблема → решение (CSS/разметка)**.

## 0. Базовые дизайн-токены (фундамент для половины фиксов)

CSS плоский: в файле ~30 оттенков серого (#333/#555/#666/#777/#888/#999/#aaa/#bbb/#ccc/#ddd/#e0e0e0/#e8e8e8/#eee/#f0f0f0/#f5f5f5/#f8f8f8/#fafafa…), 4 зелёных (#4caf50, #2a7d2a, #2e7d32, #81c784), 6 красных (#c62828, #c00, #c33, #c44, #e57373, #f44336), 4 жёлто-оранжевых (#ff9800, #f5a623, #ffc107, #ffb74d), радиусы 3/4/5/6/8/10/12 px без системы.

  /* Поверхности */
  --bg:          #f5f5f5;

  --surface-2:   #fafafa;
  /* Границы */
  --border:      #d9d9d9;
  --border-soft: #ececec;
  --border-focus:#2c2c2c;
  /* Семантика — по одному оттенку на смысл */
  --ok:      #2e7d32;   /* 5.1:1 на белом — текст и иконки */
  --ok-bg:   #e8f5e9;
  --warn:    #b26a00;   /* вместо #ff9800/#f5a623: 4.8:1 */
  --warn-bg: #fff6e5;
  --danger:  #c62828;   /* 5.6:1 */
  --danger-bg:#fdeaea;
  /* Радиусы и отступы */
  --r-s: 4px; --r-m: 6px; --r-l: 12px;
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px; --sp-5: 24px;

A3); `#c00,#c33,#c44,#e57373,#f44336 → var(--danger)`; `#ccc,#ddd,#e0e0e0 (границы) → var(--border)`. Размеры 9–10px поднять до 11px (см. C4).

## A. Доступность (WCAG AA)

### A1. [HIGH] Везде — контраст вторичного текста ниже AA
Замеры на белом фоне:
- `#bbb` — **1.9:1** (нужно 4.5:1): `.step-note`, `.pv-dropzone`, `.oc-field-empty`, `.mob-slot-empty-text`, `.te-empty`, `.mob-pipeline-step-note`, `.pv-filter-star` (незакрашенные звёзды — 1.9:1 при норме 3:1 для UI-графики);
- `#aaa` — **2.3:1**: `.empty-state`, `.project-stats`, `.cp-empty`, `.status-bar`, `.tmpl-lib-empty`;
- `#999` — **2.85:1**: подписи полей, `.auth-subtitle`, `.cp-sidebar h3`, счётчики, `.pv-toolbar span`, плейсхолдеры;
- `#888` — **3.5:1**: `.nav-btn` (неактивные вкладки главной навигации!), `.step-name`, лейблы форм.

**Решение:** после ввода токенов —
```css
.step-note, .pv-dropzone, .oc-field-empty, .mob-slot-empty-text,
.empty-state, .cp-empty, .project-stats { color: var(--text-faint); }
.nav-btn, .subtab, .auth-field label, .modal-field label,
.sync-field label, .te-group label { color: var(--text-muted); }
.status-bar { color: var(--text-muted); font-size: 12px; }
```
Иерархию «бледнее = менее важно» сохранит пара `--text-muted`/`--text-faint`; ниже 4.5:1 не опускаться.

### A2. [HIGH] Везде — фокус с клавиатуры невидим
Все кнопки (`.btn`, `.nav-btn`, `.subtab`, звёзды фильтра, стрелки каруселей, крестики) не имеют видимого фокуса; на инпутах `outline: none` с заменой на изменение цвета рамки #ddd→#333 (слабый индикатор), в 6 местах `outline:none` вообще без замены (`.oc-cnt-name-input`, `.mob-comment-input`, инлайн-стили в `cards.js:783`).

**Решение** — одно глобальное правило:
```css
:focus-visible {
  outline: 2px solid var(--border-focus);
  outline-offset: 2px;
  border-radius: var(--r-s);
}
.cp-fullscreen-overlay :focus-visible,
.rt-cmt-bar :focus-visible { outline-color: #fff; }
```
И удалить все `outline: none` из `:focus`-правил (10 вхождений в style.css + 1 в cards.js).

### A3. [HIGH] Отбор/превью — рейтинговые звёзды не читаются
`#f5a623` на белом — 2.0:1, `#ffc107` (мобильные) — 1.6:1.
```css
.pv-filter-star { color: #b5b5b5; }
.pv-filter-star.active, .mob-star-active { color: #b26a00; } /* 4.8:1 */
.mob-filter-star { font-size: 28px; padding: 8px 6px; }
```

### A4. [HIGH] Все галереи — `<img>` без alt
`previews.js:2093, 3554, 3579, 4026` — `<img>` без `alt`. Решение: `alt` из имени файла (`esc(pv.name)`), артикулы — `alt="Референс <sku>"`. Иконочным кнопкам aria-label: `.pv-remove` «Убрать фото», стрелки карусели, бургер, `.mob-slot-remove`, `.cp-fullscreen-close` (сейчас aria-label есть в 3 местах на всё приложение).

### A5. [MED] Модалки и лайтбокс — нет семантики диалога
`role="dialog" aria-modal="true"` только у `pv-rm-modal`. В `openModal()`: role/aria-modal/tabindex=-1/focus() + Esc в одном keydown на document.

### A6. [MED] Мобильный клиент — нет заголовков-ориентиров
`.mob-card-divider` («Карточка 1 / 42») сделать `<h2>` + visually-hidden заголовок страницы.

## B. Мобильный клиент (share-ссылка, ~380px)

### B1. [HIGH] Вкладки на английском: Cards / Select / Other / Options
`cards.js:2805–2808`. Решение: Карточки / Отбор / Другое / Варианты (паддинги `6px 10px`).

### B2. [HIGH] Карусель в слоте никак не обнаруживается
Стрелки и индикатор «2/5» появляются только после тапа, автоскрытие через 4 с. Решение: индикатор позиции показывать постоянно при >1 фото (скрывать только стрелки); точки вместо цифр при ≤5 фото; одноразовая подсказка «В каждом слоте несколько вариантов — листайте фото свайпом» (localStorage-флаг).

### B3. [HIGH] Touch-таргеты меньше 44px
`.mob-carousel-arrow` 36px, `.mob-slot-remove`/`.mob-slot-zoom` 28px, `.mob-gallery-check` 28px, `.mob-burger` 32px, `.mob-card-menu-close` ~24px, звёзды ~28px, `.mob-comment-send` ~34px. Решение: стрелки 44px; остальным `::after { content:''; position:absolute; inset:-8px; }` хитбоксы.

### B4. [HIGH] Согласование — необратимое действие без объяснения последствий
«Просмотр завершён» под последней карточкой даже если смотрел 2 из 42; системный `confirm()`/`alert()`. Решение: 1) счётчик «Просмотрено карточек: 17 из 42» (IntersectionObserver по `.mob-card-divider`); 2) заголовок «Готовы завершить согласование?»; 3) bottom-sheet в стиле `.mob-cnt-picker-sheet` («42 карточки будут переданы на цветокоррекцию. Фотограф получит уведомление»); 4) после успеха — статус «Отбор согласован · 2 июля, 14:32 · Мария» вместо alert.

### B5. [MED] Комментарий — кнопка «OK» и немой плейсхолдер
Плейсхолдер «Замечание ко всей карточке...», кнопка «Отправить»; хинт при первом использовании «Комментарий увидит вся команда».

### B6. [MED] «Карточка N / 42» вместо имени товара
Показывать `card.name`: «№ 7 — Туфли ALX-T201».

### B7. [MED] Пустые слоты в клиентской ленте
«Фото ещё не подобрано»; скрывать пустые слоты для роли viewer.

### B8. [LOW] 16px = минимум для мобильных полей ввода — закрепить (`--fs-l`).

## C. Фотограф (desktop)

### C1. [HIGH] Панель превью не рассчитана на «тысячи фото»
4957 превью одной flex-стеной: тормоза, поиск только глазами. Решение: 1) виртуализация при >300 (окно видимого, justified-layout уже посчитан); 2) поиск по имени файла над галереей; 3) группировка по папкам со сворачиванием.

### C2. [HIGH] Тулбар проектов: 7 кнопок одного веса
«Скачать лог» рядом с «Новая съёмка». Решение: primary «Новая съёмка» + «Поделиться»; Команда/Экспорт/Импорт/Лог — в дропдаун «Ещё ▾» (паттерн `.sh-jump-menu` есть); «Выйти» — к имени в статус-баре.

### C3. [MED] Статус сохранения почти невидим + статус-бар перекрывает контент
`padding-bottom: 48px` контейнерам; `--text-muted` статус-бару; `.connected { color: var(--ok); }`.

### C4. [MED] Микрокегли 9–10px (`.pv-name` 9px и др.) — минимум 11px + `tabular-nums` для имён файлов.

### C5. [MED] Управление только с hover — дублировать `:focus-within` + `tabindex="0"` на плитках.

### C6. [LOW] Пайплайн done-этапы: убрать opacity, управлять цветом.

### C7. [LOW] Sync: итог «Готово: N/M» поднять наверх, рамка `--ok`/`--warn`.

## D. Состояния

### D1. [HIGH] 60+ системных `alert()`
Особо опасно `articles.js:1860`: «ОК = заменить все, Отмена = добавить» — Отмена выполняет действие. Решение: общий `toast(msg, kind)` + модалка подтверждения (стили `.modal` есть); для «заменить/добавить» — модалка с кнопками «Заменить все» / «Добавить к существующим» / «Отмена». Мигрировать сначала клиентские пути.

### D2. [MED] Пустые экраны — тупики. Каждый empty-state = 1 фраза + 1 кнопка действия.

### D3. [MED] Оффлайн молчалив. Sticky-баннер: «Нет соединения — изменения сохраняются на устройстве и отправятся автоматически»; при восстановлении — тост.

### D4. [MED] Загрузка share-ссылки — голое «Загрузка...» ~6 с. Брендированный лоадер + скелетон 3 карточек; постраничная отдача если RPC позволит.

### D5. [LOW] Паттерн «Загрузка: 120/300 (40%)» — распространить на загрузку версий.
