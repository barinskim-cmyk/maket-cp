# Cardboard — вёрстка карточек товара

Standalone-инструмент семейства Content Pulse (как Rate Setter). Один HTML-файл, без бэкенда, без установки: скачал → открыл в браузере → работаешь.

## Что делает

1. **Закидываешь фото** — drag-and-drop на окно, кнопкой «Добавить фото», или через слежение за папкой.
2. **Собираешь карточки** — сетка по шаблону (2×2, 3×2, 3×3...), фото перетаскиваются из левой панели в слоты, слоты меняются местами, сетка расширяется на лету.
3. **Структурируешь доп. контент** — свободные контейнеры: фото в произвольном порядке (S/M/L), перестановка перетаскиванием, комментарий к блоку.
4. **Выгружаешь**:
   - **PDF** — печатная раскладка карточек и контейнеров (диалог печати → «Сохранить как PDF»);
   - **Список** — CSV (для Excel) + TXT: какой файл в какой карточке на какой позиции.

## Синхронизация с Capture One (хоткей)

1. В Capture One создать экспорт-рецепт (JPEG, любая папка, например `~/Pictures/cardboard-inbox`) и назначить хоткей на «Export with recipe».
2. В Cardboard нажать «Следить за папкой» и выбрать эту папку.
3. Дальше: выделил фото в Capture One → хоткей → через пару секунд фото уже в панели Cardboard.

Слежение за папкой работает в Chrome и Edge (File System Access API). В Safari — только drag-and-drop и кнопка.

## Проекты

«Сохранить» выгружает файл `имя.cardboard` (JSON, фото внутри — миниатюры до 1400 px). «Открыть» восстанавливает проект полностью на любом компьютере — исходники фото не нужны.

## Технически

- Один файл `index.html`, чистый JS без фреймворков и внешних зависимостей.
- Фото при импорте сжимаются до 1400 px JPEG — исходники не изменяются и никуда не загружаются, всё остаётся на компьютере.
- Префикс функций: `cb*`. Модель данных: `App.photos / App.cards / App.containers`.

## Проверка

Смоук-тест (playwright): импорт, карточка 3×2, дроп в слот, ресайз сетки, контейнер, дубликаты, экспорт списка и PDF-разметки, сохранение/восстановление проекта — 14 проверок, все зелёные (04.07.2026).
