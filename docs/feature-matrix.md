## Smoke-сценарии (проверены 2026-07-02, все зелёные)

1. **Веб-клиент загружается**: анонимный пользователь видит auth-gate. PASS
2. **Share-ссылка (client)**: проект открывается по токену, 42 карточки рендерятся, 0 JS-ошибок. PASS
3. **Невалидный токен**: приложение не падает (но и не сообщает об ошибке — доработка). PASS
4. **Лендинг**: hero Version A, нет устаревших формулировок, форма-маршрутизатор видна. PASS (3 теста)

Файлы: `tests/e2e/active/product-smoke.spec.ts`, `tests/e2e/active/landing-smoke.spec.ts`. CI блокирует красный прогон (continue-on-error снят 02.07).

End-to-end сценарии для будущих тестов: (а) создать проект → загрузить фото → собрать карточку → синхронизировать; (б) share → клиент меняет фото в слоте → согласовать → фотограф видит; (в) возврат с комментарием → правка → повторный аппрув; (г) Rate Setter dry-run → live; (д) чек-лист PDF → AI-match → верификация → CSV; (е) оффлайн-правки → reconnect → sync.

## Предложения (новые функции / доработки)

Приоритет 1 — закрывают дыры ролей:
1. **Сообщение «Ссылка недействительна»** при невалидном/отключённом токене вместо пустого UI фотографа. Мелко, найдено smoke-тестом.
2. **Режим ретушёра**: очередь фото → загрузка результата → версия → видит комментарии/аннотации (уже в бэклоге audit0702-retoucher-mode; compare-view вывести из-под флага).
3. **Мобильные комментарии/аннотации клиента**: маркеры-кружки тапом, текст к карточке (audit0702-mobile-select уточнён: выбор фото работает, дыра — именно аннотации).
4. **Уведомления фотографу** (email или telegram) при аппруве/возврате/комментарии клиента — сейчас узнаёт, только открыв приложение. Главный кандидат на retention.

Приоритет 2 — доводка фотографского контура:
5. **Нативное переименование** (rename_in_folder) — убрать зависимость от отдельного .exe.
6. **Горячая клавиша «в карточку»** в живой съёмке (Cmd+Shift+C).
7. **Онбординг: демо-проект** при первой регистрации — видно ценность без установки desktop-приложения.
8. **Шаблон из прошлой съёмки** — скопировать структуру карточек существующего проекта (для повторных клиентов).
