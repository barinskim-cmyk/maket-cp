# Инструменты Content Pulse — табличка для анонсов

Семейство маленьких бесплатных инструментов для съёмочной рутины. Каждый оставляет после себя простой файл, которым пользуется следующий — вместе они складываются в конвейер продакшена.

| Инструмент | Что делает | Статус | Платформы | Скачать |
|---|---|---|---|---|
| **Rate Setter** | Быстрая синхронизация финального отбора с Capture One: рейтинг и метка одним нажатием по списку выбранных кадров | Готов | Mac + Windows | github.com/barinskim-cmyk/content-pulse-rate-setter/releases/latest |
| **Cardboard** | Быстрая сборка карточек товара + разметка дополнительного контента (соцсети, продуктовые имиджи) → PDF для клиента. Всё локально, обновляется сам. Дальше по плану: клиент редактирует отбор с телефона по ссылке (уже работает, но лагает — доступно пока только Маше) | Готов | Mac + Windows | github.com/barinskim-cmyk/content-pulse-cardboard/releases/latest |
| **Analyzer** | Отчёт по смене из файлов Capture One: время на артикул, паузы, темп, топ самых долгих — и «эффективное vs потраченное» время. PDF + CSV | В разработке | Mac + Windows | скоро |

## Формулировка для поста («вот два, а будет вот что»)

Два инструмента уже можно скачать — Rate Setter и Cardboard. Но это только начало: следующим выйдет Analyzer — он читает вашу сессию Capture One и показывает, куда ушло время смены: сколько занял каждый артикул, где были паузы, какие кадры дались легко, а какие искали полчаса. Дальше — Estimator, который по накопленным отчётам считает смету следующей съёмки, планировщик смены и генератор заданий ретушёру. Все инструменты бесплатные, работают локально с вашими файлами и дружат между собой: то, что сделал один, умеет читать следующий.

| **Retoucher** (ИИ-ретушь) | Пакетная ретушь по твоему стилю: эталонные пары «до/после» как референс + правки из Review → API (image-editing модель) → отретушированные кадры обратно в проект | Видение (~год) | — | платно (API) |

## Монетизация семейства (первая точка)

Все инструменты бесплатны в ручном режиме. Первая платная функция — ИИ-сопоставление в Renamer (реальные расходы на API + очевидная ценность: не перекладывать 500 кадров руками). Модель «бесплатно руками / за деньги автоматом» — шаблон и для будущих ИИ-функций других инструментов.

## Правила упоминания

- Никаких обещаний дат — только порядок («следующим выйдет...»).
- Реальные названия брендов клиентов в примерах не используем.
- Ссылки в IG некликабельны — «ссылка в шапке профиля», сами ссылки в био (см. docs/instagram-tools-post.md).
