## Текст поста — вариант 1 (короткий)

Сделала два бесплатных инструмента для съёмочной рутины — пользуюсь сама каждый день, теперь отдаю вам.

CARDBOARD — вёрстка карточек товара. Кидаешь фото из Capture One, раскладываешь по шаблонам на листах A4, на выходе — готовый PDF для клиента. Шаблоны свои, фон любой, фото не копируются и не грузятся в облако — всё живёт у тебя на компьютере.

RATE SETTER — отбор одним хоткеем: рейтинг и метка сразу в сессию Capture One по списку выбранных кадров. Больше не щёлкать по одной.

Оба бесплатные, без регистраций. Ссылки в шапке профиля: скачал, открыл, работаешь. Mac (Rate Setter — ещё и Windows).

Если macOS спросит про «неустановленного разработчика» — это норма для программ не из App Store: правый клик → Открыть (или Настройки → Конфиденциальность → «Открыть всё равно»). Инструкция лежит рядом со скачиванием.

## Текст поста — вариант 2 (личный, история)

Каждая съёмка каталога заканчивалась одинаково: сотни кадров, Excel с артикулами и полночная вёрстка карточек руками. Надоело — и я сделала себе инструменты. Теперь делюсь.

CARDBOARD собирает карточки товара из твоих фото по шаблонам и отдаёт PDF постранично, один в один как на экране. RATE SETTER ставит рейтинг и метку в Capture One по списку отобранных кадров одним нажатием.

Всё локально: твои фото остаются на твоём компьютере, ничего никуда не загружается. Бесплатно, без регистрации, приложения обновляются сами. Ссылки в шапке профиля.

Это часть Content Pulse — платформы для визуального продакшена, которую я строю. Пользуйтесь и пишите, чего не хватает: инструменты растут из реальных съёмок.

## Текст для сторис / закреплённого хайлайта «Установка»

Слайд 1: Скачай по ссылке в шапке профиля. Регистрация не нужна.
Слайд 2: Распакуй и перетащи приложение в «Программы».
Слайд 3 (Mac): При первом запуске macOS перестрахуется — правый клик → Открыть. На новых macOS: Настройки → Конфиденциальность и безопасность → «Открыть всё равно». Это один раз.
Слайд 4: Если спросит доступ к папке с фото — «Разрешить». Всё, работаем.

## Если спросят «а это безопасно?» (готовый ответ в комментарии)

Да. Программы собирает не мой ноутбук, а сервер GitHub из открытого исходного кода — код виден всем, подмена исключена, к каждому файлу приложена криптографическая подпись сборки и контрольная сумма. Можно проверить любой файл на virustotal.com — его просканируют ~70 антивирусов. Предупреждение macOS при первом запуске — стандартное для всех программ не из App Store.
